# 提供価値

## 背景

東京は、地方から見ると「資本が集中する街」「人が多く、混雑している街」という印象を持たれやすく、歴史的・文化的な魅力が十分に認識されていない可能性がある。

しかし実際の東京には、江戸から続く暮らしや地域ごとの文化、建築、産業、自然など、多様な物語が街の中に残されている。

本アプリでは、ランドマークを巡る体験を通じて、利用者がそれらの魅力を自ら発見し、東京に対する見方を変えられる価値を提供する。

## 中心となる提供価値

> ランドマークを自分の足で巡り、その場所に残る歴史や文化を知り、体験を振り返ることで、東京に対する新しい見方を持ち帰れる。

単にランドマークの情報を提示するのではなく、利用者自身による探索、発見、記録、振り返りを一つの体験として提供する。

この体験によって、東京を「消費する街」から「物語を発見する街」へと捉え直してもらう。

## 体験の流れ

1. 地図を見て目的地を探す
2. 実際にその場所を訪れる
3. ランドマークの歴史的・文化的背景を知る
4. 現地での発見や感想を記録する
5. 訪れた場所と得られた気づきを、一つの旅として振り返る

## 一般利用者にとっての価値

- 有名な観光地を眺めるだけでなく、その背景まで理解できる
- 混雑や利便性だけではない東京の魅力に気づける
- ランドマークの踏破によって、探索する動機と達成感を得られる
- 訪問履歴や発見を、自分だけの東京体験として残せる
- 普段は通り過ぎてしまう場所にも意味を見つけられる

アプリが東京の魅力を一方的に決めて教えるのではなく、利用者が自ら見つけられるようにすることを重視する。

## 学校教育における価値

小学校などに提供する場合は、街歩きと学習を組み合わせたフィールドワーク教材として活用できる。

- 地図を読み、現在地や経路を把握する力を育てる
- 地域の歴史や文化への理解を深める
- 現地を観察し、疑問や関心を持つ力を育てる
- 発見したことを記録し、整理する力を育てる
- グループで相談しながら行動する経験を得る
- 活動後に体験を振り返り、言葉で表現する力を育てる

知識を覚えてから現地へ行くのではなく、現地での発見を学びの入口にできる点を、本アプリならではの教育的価値とする。

## 企画説明文

東京のランドマークを巡る体験を通じて、街に蓄積された歴史・文化・地域の物語を発見できるまち歩きアプリです。地図を頼りに自ら目的地を訪れ、現地で得た気づきを記録し、最後に一つの旅として振り返ることで、「混雑した資本の街」という東京の印象を、「多様な物語が息づく街」へと変えていきます。観光だけでなく、子どもたちの地図読解、地域学習、観察、振り返りを支援するフィールドワーク教材としても活用できます。

## コンセプトコピー

> **歩いて、見つけて、振り返る。東京を「知っている街」から「自分で発見した街」へ。**
